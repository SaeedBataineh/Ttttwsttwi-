CLIPPED DAILY

Privacy Policy

Last updated: November 17, 2026

Clipped Daily is a private tool used only by the owner of the Clipped Daily channel to publish videos to that channel. It is not offered to the public, and no one else signs in to it.

What Google data the app uses

When the channel owner signs in with Google, the app asks for permission to upload videos to their YouTube channel and to read the channel's name. It uses this access only to upload videos the owner has approved and to confirm which channel it is connected to.

How the data is stored

The sign-in token is stored only on the owner's own computer or server. It is not sent to anyone else, sold, shared or used for advertising. The app does not collect data about viewers or any other YouTube users.

Twitch data

The app reads public clip information from Twitch (titles, view counts and the clip videos) to choose which clips to feature.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions, and delete the stored token by deleting the app's data folder.

Use of Google API data

Clipped Daily's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploads use the YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Contact

Questions or removal requests: contact us through the Clipped Daily YouTube channel.
