# Clipped Daily branding

- `profile-800.png`: profile picture for YouTube, TikTok and Instagram (they crop it to a circle; the mark is centered for that)
- `youtube-banner-2560x1440.png`: YouTube channel banner (text sits inside the mobile-safe area)
- `icon.svg`: the logo as a vector, for any size

Colours: background `#0B0B0D`, yellow `#FFD60A` (same as the caption highlight). Regenerate the PNGs with `node render.js` in this folder.
